# Getting help

- **Your account, a send or a bill:** email support@dropcowboy.com. Don't post
  keys, phone numbers or customer data in a public issue.
- **How the API works:** the [developer hub](https://www.dropcowboy.com/developers)
  and its [troubleshooting guide](https://www.dropcowboy.com/developers/api/troubleshooting).
- **Is something down?** [System status](https://status.dropcowboy.com).
- **A bug in code in one of our repositories:** open an issue there.
