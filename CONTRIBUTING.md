# Contributing

Thanks for helping. Issues and pull requests are welcome on Drop Cowboy's
public repositories.

- Keep each pull request to one change, and say what it fixes.
- Use placeholders, never real data: phone numbers like `+15555550123`,
  emails at `example.com`, and keys like `YOUR_KEY`.
- Ids in examples are plain UUIDs, like
  `d1f3a8e2-7c4b-4f9a-9d22-9c1e2f3a4b5c`. No prefixes.
- Check facts against the [API docs](https://www.dropcowboy.com/developers/api).
- A problem with your account, a send or a bill goes to
  support@dropcowboy.com, not an issue. Issues are public.
- Security problems: see [SECURITY.md](SECURITY.md).

A repository with its own `CONTRIBUTING.md` may add rules; follow those there.
